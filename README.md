# Sign-Up Form (Travel Tales)

A responsive account-creation form built to practice **client-side form structure and
layout** with HTML and CSS — semantic fields, focus/invalid styling, and password
confirmation feedback.

🔗 **Live demo:** [sign-up-one-liart.vercel.app](https://sign-up-one-liart.vercel.app/)

![Sign-up form preview](docs/assets/preview.png)

## Features

- Responsive two-column layout (image/brand panel + form) that adapts down cleanly.
- Semantic, labeled inputs for accessible account creation.
- Focused and invalid field styling for clearer feedback.
- Password-confirmation feedback.

## Tech stack

HTML · CSS (with light JavaScript for validation feedback)

## Getting started

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

## What I practiced

Semantic, accessible **form markup**, CSS for focus/`:invalid` states, and a responsive
two-column layout.
